# فایل‌هایِ بارگذاری‌شده

هر فایلی که از پنلِ مدیریت («انتخاب فایل از سیستم») بارگذاری شود اینجا
ذخیره می‌شود و از نشانیِ `/files/<نام>` خوانده می‌شود.

- نامِ فایل با GUID ساخته می‌شود؛ نامِ اصلی ذخیره نمی‌شود.
- فقط تصویر: `png`, `jpg`, `jpeg`, `webp`, `avif`, `gif` — حداکثر ۴ مگابایت.
- این پوشه را پاک نکنید؛ نشانیِ تصویرها در پایگاه‌داده به همین فایل‌ها
  اشاره می‌کند.
